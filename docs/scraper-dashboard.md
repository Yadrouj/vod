# داشبورد خصوصی اسکریپرها

داشبورد در مسیر `/admin/scrapers` قرار دارد و وضعیت زمان‌بندی، آخرین بررسی، تعداد دریافت‌شده، پردازش و خطاهای jobهای نگهداری را نشان می‌دهد.

## دسترسی

در production حتماً یک توکن طولانی و تصادفی تنظیم کنید:

```dotenv
SARVNEMA_ADMIN_TOKEN=یک-توکن-تصادفی-طولانی
```

توکن در `sessionStorage` مرورگر مدیر نگهداری می‌شود و با header `x-admin-token` به API ارسال می‌شود. بدون توکن، API در production پاسخ `401` می‌دهد. در development برای راحتی محلی، اگر متغیر تنظیم نشده باشد API باز است؛ این حالت را روی سرور عمومی استفاده نکنید.

## امکانات

- تنظیم بازهٔ اصلی، منطقهٔ زمانی و روزهای اجرا
- فعال/غیرفعال‌کردن هر scraper و تعیین بازه و روزهای مخصوص همان منبع
- نمایش وضعیت در حال دریافت، تکمیل‌شده، انتظار و خطا
- نمایش آخرین زمان بررسی، تعدادهای گزارش‌شده و مرحلهٔ جاری
- ثبت سایت جدید به‌عنوان منبع دستی

ثبت سایت جدید فقط آن را در رجیستری داشبورد ذخیره می‌کند و اجرای کد یا scraper دلخواه از URL انجام نمی‌شود. برای دریافت واقعی از یک سایت تازه، باید adapter امن و تست‌شدهٔ آن منبع به `DAILY_JOBS` اضافه شود.

تنظیمات در `data/scraper-dashboard.json` ذخیره می‌شوند. تریگر روزانهٔ `maintenance-scheduler.mjs` این فایل را در هر چرخه می‌خواند؛ در نتیجه تغییرات از چرخهٔ بعدی اعمال می‌شوند.
